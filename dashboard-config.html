📺 Dashboard Config

Configure the School Dashboard

Sign in with your admin Google account to configure the dashboard.

🎨 Canva

Open your Canva presentation, click Share → More → Embed, and paste the URL.
The URL ends in /view?embed. Canva handles its own auto-play loop — the dashboard does not reload the iframe on a timer, so the presentation plays continuously without interruption.
Leave blank to show the school logo instead.

🕐 Schedules

📊 House Scores Sheet

Open your scores sheet, File → Share → Publish to web, choose Comma-separated values (.csv), click Publish, and paste the generated URL.
Expected structure: row 1 = house names (headers), row 2 = scores. Columns A=Accomodore, B=Callidus, C=Princeps, D=Vevaios.
The dashboard fetches this every 5 minutes.

🎂 Birthday Ticker

The band at the top of the signage right column. All three sheets are optional — leave them blank and the ticker just shows the fallback line below.
Publish the individual TAB, not "Entire Document" (File → Share → Publish to web → pick the tab → Comma-separated values). Publishing the whole document would publish your private roster with it.

Two columns: display name, then month/day. Expected structure: row 1 = headers, rows below = one student each.
Optional third column: house (Accomodore, Callidus, Princeps or Vevaios) — the card then shows in that house's colour. Blank or anything else gets the ordinary tile.
This tab should be a FORMULA over your private roster tab, so that the published URL never carries a birth year, a full last name, or anyone who has opted out. See HANDOFF.md §7 for the formula.

Same columns as the student feed, including the optional house, but the name reads "Mr. Wilson" rather than "John S." — faculty get titles and full surnames, students get first name and last initial.
Faculty are pooled with the students: same greeting, same early wishes over breaks, and they count toward the two-item minimum. Optional — leave blank for students only.

Three columns: start date, end date (leave blank for a single day), label.
Do not list weekends — the ticker works those out. List only the weekdays school is closed; a break that touches a weekend is joined up automatically. Without this sheet, only weekends count as days off.

Four columns: month/day (as text, e.g. 07/08), name, context (optional), no-Happy (optional).
The ticker shows each name as "Happy <name>!" — put anything in the fourth column for rows that must not be (memorials like Patriot Day). A context sentence gets its own card, right after the name.
No birthdays that day: every event is shown. One birthday: one event. Two or more: none.

Normally a day with two or more birthdays shows no events, one birthday shows one, and none shows them all. This is a floor under that rule, never a cap — "At least 1" still shows every event on a day with no birthdays.

Opens the right column showing that day's ticker — birthdays, early wishes, closures and events — with an amber PREVIEW badge. Uses the settings as last saved, so Save first if you just changed something. Nothing here changes what the TVs show.

Shown when there is no birthday and no holiday for the day, so the band is never empty.

The band flips between the two, so a quiet day still rotates instead of showing one line to itself. Leave blank to just repeat line 1. Long lines are fine — the ticker sizes each line to fit.

📣 Announcements

Up to five messages shown in the ticker on top of the normal birthdays and events — reminders, local celebrations, schedule changes. They reach the TVs within seconds of Save, no reload needed. Set dates and they switch themselves on and off; leave dates blank to show until you switch it off. Once a slot says Expired, it's free to reuse.
